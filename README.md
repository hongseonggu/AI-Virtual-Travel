# AI-Virtual-Travel
> **LLM 기반 스토리텔링과 실시간 비주얼 생성을 결합한 멀티모달 가상 여행 웹 서비스**

---

## 프로젝트 개요 (Project Overview)

"AI 가상 여행"은 사용자가 선택한 여행지와 여행 스타일에 따라 AI가 실시간으로 독창적인 세계관과 스토리를 생성하고, 그에 어울리는 이미지를 즉석에서 렌더링해 주는 **텍스트 기반 어드벤처 & 멀티모달 스토리텔링 서비스**입니다.

정해진 시나리오를 따라가는 기존 게임과 달리, 사용자는 AI가 제공하는 **객관식 선택지**를 누르거나 **자유 입력(주관식)**을 통해 자신이 원하는 행동을 입력함으로써 무한한 가능성의 가상 세계를 직접 모험할 수 있습니다.
